About

What is CDC Team Zemo?

"CDC Team Zemo" refers to the CDC Placement Portal — a production-grade college placement management system developed by Surendra Singh Chouhan, Core Member of Team Zemo.

The platform digitizes the entire college placement workflow, providing secure access for students, faculty, and placement officers with granular role-based controls.

Live Platform: The CDC Portal is deployed at cdc.acropolis.teamzemo.tech and serves Acropolis Institute of Technology and Research, Indore.

Spring Boot JWT Auth RBAC MFA / TOTP Docker PostgreSQL Apache POI Async Processing
Features

CDC Platform Key Features

🔐

JWT Authentication

Secure token-based authentication with refresh token management and session control.

👥

Role-Based Access Control

Granular RBAC for students, faculty, placement officers, and administrators.

📱

MFA / TOTP

Multi-Factor Authentication via Time-based One-Time Passwords for enhanced security.

📊

Placement Analytics

Real-time placement statistics, student filtering, and performance dashboards.

📥

Excel Exports

Bulk data export using Apache POI for placement reports and student data.

⚡

Async Processing

High-performance async job processing, caching with Redis, and scheduled tasks.
